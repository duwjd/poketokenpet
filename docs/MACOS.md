# macOS에서 실행하기

받는 사람이 개발자가 아니어도 됩니다. 다만 **한 번은 Gatekeeper를 넘어야** 합니다.
그 한 번이 이 문서 전부입니다.

---

## 1. 맞는 파일 받기

애플 메뉴  → **이 Mac에 관하여** → `칩` 줄을 봅니다.

| 칩 | 받을 파일 |
|---|---|
| Apple M1 / M2 / M3 / M4 | `PokeTokenPet-<버전>-arm64-mac.dmg` |
| Intel Core ... | `PokeTokenPet-<버전>-x64-mac.dmg` |

틀린 걸 받으면 실행이 안 되거나(Intel 빌드를 Apple 칩에서 돌리면 Rosetta로 느리게
돌아갑니다) 아예 안 열립니다. `.zip`도 같이 올라와 있는데 내용물은 같습니다 —
dmg가 편하면 dmg를 받으세요.

## 2. 설치

dmg를 열고 **PokeTokenPet.app을 Applications 폴더로 끌어다 놓습니다.**

## 3. "손상되었기 때문에 열 수 없습니다"

첫 실행에서 이게 뜹니다:

> **"PokeTokenPet"은(는) 손상되었기 때문에 열 수 없습니다. 해당 항목을 휴지통으로
> 이동해야 합니다.**

**앱이 손상된 게 아닙니다.** macOS가 인터넷에서 받은 파일에 격리(quarantine)
딱지를 붙이는데, 이 앱은 코드 서명이 없어서 딱지를 뗄 근거를 시스템이 못 찾는
것뿐입니다. 서명 인증서는 연 $99라서 개인 프로젝트에 붙이지 않았습니다.

넘어가는 방법은 macOS 버전에 따라 둘입니다.

### 방법 A — 시스템 설정 (macOS Sequoia / 15 이상)

1. 위 경고창에서 **취소**를 누릅니다 (휴지통으로 이동 아님!)
2. **시스템 설정 → 개인정보 보호 및 보안**
3. 아래로 스크롤하면 *"'PokeTokenPet'이(가) 차단되었습니다"* 줄이 있습니다
4. 옆의 **그래도 열기** 클릭 → 암호 입력

> Sequoia부터는 **앱을 우클릭 → 열기가 더 이상 통하지 않습니다.** 예전 안내를
> 보고 우클릭을 아무리 해도 안 되는 게 정상입니다. 반드시 시스템 설정으로 가세요.

### 방법 B — 터미널 한 줄 (모든 버전)

격리 딱지를 직접 뗍니다:

```bash
xattr -dr com.apple.quarantine /Applications/PokeTokenPet.app
```

그 뒤 평소처럼 실행하면 됩니다. 이 명령은 **그 앱 하나의 격리 표시만** 지웁니다.
시스템 보안 설정을 건드리지 않습니다.

한 번 통과하면 그 다음부터는 아무 창도 안 뜹니다.

## 4. Claude Code가 깔려 있어야 합니다

이 앱은 **로그를 읽기만 합니다.** `~/.claude/projects/`를 봅니다.

Claude Code를 쓴 적이 없으면 그 폴더가 없고, 앱은 안내 문구를 띄우고 기다립니다.
깨지지는 않습니다. Finder에서 `⌘⇧G` 후 `~/.claude`를 붙여넣어 확인할 수 있습니다.

`CLAUDE_CONFIG_DIR`로 위치를 바꿔 쓰고 있다면, Finder에서 실행한 앱은 셸 환경변수를
물려받지 못합니다 — 앱 안의 **설정** 탭에서 경로를 직접 지정하세요.

## 실행하면 이렇게 됩니다

- **메뉴바(시계 옆)에 아이콘 + 오늘 토큰** (`355.2M`). 클릭하면 패널이 열립니다
- **Dock 아이콘은 없습니다.** 메뉴바 전용 앱입니다(`LSUIElement`). 종료는 패널이
  아니라 메뉴바 아이콘 메뉴에서 합니다
- 아이콘은 검정+알파 템플릿이라 다크모드에서 자동 반전됩니다
- 화면 위에 떠 있는 펫 창은 설정에서 끌 수 있습니다

## 지우려면

1. `/Applications/PokeTokenPet.app`을 휴지통으로
2. 게임 상태와 스프라이트 캐시는 `~/.poketokenpet/`에 있습니다. 통째로 지우면
   완전히 사라집니다

`~/.claude/` 안의 것은 이 앱이 만든 게 아니므로 건드리지 마세요.

## 직접 빌드하고 싶다면

서명 없는 바이너리가 찜찜하면 이게 제일 확실합니다. 직접 빌드한 앱은 인터넷에서
받은 게 아니라서 격리 딱지 자체가 안 붙고, 위 3번 과정이 통째로 필요 없습니다.

```bash
git clone <이 저장소>
cd poketokenpet
npm ci
npm run app:dist        # release/ 에 dmg와 zip이 생깁니다
```

Node 22 이상이 필요합니다.
