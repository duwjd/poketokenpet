# Windows에서 실행하기

받는 사람이 개발자가 아니어도 됩니다. 압축 풀고 실행하면 끝입니다.

---

## 받은 사람이 할 일

### 1. 압축 풀기

`PokeTokenPet-<버전>-x64-win.zip`을 받아서, **압축을 먼저 풉니다.**

> 탐색기에서 zip 안을 들여다보며 바로 실행하면 안 됩니다. Windows가 zip을 임시
> 폴더에 풀어서 실행하는데, 옆에 있어야 할 `resources` 폴더가 딸려가지 않아
> 트레이 아이콘이 사라지거나 그냥 안 뜹니다. **반드시 폴더로 풀어서** 실행하세요.

풀어놓을 위치는 아무데나 괜찮지만, `Program Files`는 피하세요 (관리자 권한이
필요해집니다). `C:\Users\<이름>\Apps\PokeTokenPet` 정도가 무난합니다.

### 2. SmartScreen 통과

`PokeTokenPet.exe`를 처음 실행하면 파란 창이 뜹니다:

> **Windows의 PC 보호**
> Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.

**추가 정보** → **실행**을 누르면 됩니다. 한 번만 하면 그 뒤로는 안 뜹니다.

이건 바이러스 판정이 아니라 **코드 서명이 없다**는 뜻입니다. Windows 코드
서명 인증서는 연 $300~400이라 개인 빌드에는 붙이지 않았습니다. 찜찜하면
받는 사람이 직접 소스에서 빌드하는 방법이 아래에 있습니다.

### 3. Claude Code가 깔려 있어야 합니다

이 앱은 **로그를 읽기만 합니다.** `%USERPROFILE%\.claude\projects\` 를 봅니다.
(`%APPDATA%`가 아닙니다 — 흔한 오해입니다.)

Claude Code를 쓴 적이 없으면 그 폴더가 없고, 앱은 안내 문구를 띄우고 기다립니다.
깨지지는 않습니다.

주소창에 `%USERPROFILE%\.claude` 를 붙여넣어 폴더가 있는지 확인할 수 있습니다.

## 실행하면 이렇게 됩니다

- **트레이(시계 옆)에 포켓몬 아이콘.** 클릭하면 패널이 열립니다.
  - Windows 트레이에는 **숫자를 표시할 수 없습니다** (macOS 전용 기능이라).
    토큰 수는 아이콘에 마우스를 올리면 툴팁으로 나옵니다.
  - 아이콘이 `^` 안에 숨어 있으면, 끌어다 시계 옆에 고정해두면 됩니다.
- **바탕화면에 떠 있는 펫.** 드래그로 이동, 휠로 크기 조절, 더블클릭하면 패널.
- 데이터는 `%USERPROFILE%\.poketokenpet\` 에 쌓입니다. 지우면 초기화됩니다.

첫 실행 때 **지금까지 쓴 토큰은 기준선으로 잡고 0부터 셉니다.** 안 그러면
그동안 쌓인 사용량 때문에 알이 즉시 최종 진화해서 게임이 시작도 전에 끝납니다.

## 어떤 zip을 줘야 하나

| 파일 | 대상 |
|---|---|
| `...-x64-win.zip` | **대부분 이겁니다.** 보통의 Intel/AMD Windows PC |
| `...-arm64-win.zip` | Snapdragon 등 ARM Windows (Surface Pro 11 같은) |

**헷갈리면 x64를 주세요.** ARM 기기는 x64 앱을 에뮬레이션으로 돌릴 수 있지만,
반대는 안 됩니다 — arm64 빌드는 일반 PC에서 아예 실행되지 않습니다.

받는 사람 PC 확인법: 설정 → 시스템 → 정보 → **시스템 종류**.

## 보내는 쪽에서 빌드하기

```bash
npm run app:build                      # 렌더러 + 메인 번들
npx electron-builder --win            # release/ 에 x64 + arm64 zip 생성
```

Mac에서 Windows 빌드가 됩니다 — zip 타겟은 Wine이 필요 없습니다.
(NSIS 설치 프로그램을 만들려면 Wine이 필요합니다. 그래서 zip을 씁니다.)

> `electron-builder.yml`의 `win.target`에 **`arch`를 반드시 적어둬야 합니다.**
> 안 적으면 빌드하는 컴퓨터의 아키텍처를 따라가서, Apple Silicon Mac에서
> 빌드하면 **일반 Windows PC에서 안 돌아가는 arm64 zip이 조용히 만들어집니다.**

파일이 ~140MB라 메일 첨부는 안 됩니다. 드라이브/드롭박스 링크로 보내세요.

## 받는 사람이 직접 빌드하려면

서명 없는 exe를 받기 찜찜하다면 이쪽이 낫습니다. Node 22 이상이 필요합니다.

```powershell
git clone <저장소 주소>
cd poketokenpet
npm install
npm run app:build
npx electron-builder --win --x64 --dir   # release\win-unpacked\PokeTokenPet.exe
```

자기 PC에서 만든 exe라 SmartScreen도 훨씬 덜 깐깐합니다.

## 안 될 때

| 증상 | 원인 |
|---|---|
| 트레이 아이콘이 없다 | zip 안에서 바로 실행함. **풀어서** 실행하세요 |
| 실행해도 아무 일도 안 남 | 이미 떠 있습니다. 트레이 `^` 안을 확인 |
| 토큰이 계속 0 | Claude Code 미설치, 또는 아직 쓴 적 없음 |
| 펫이 안 보임 | 트레이 → 설정에서 껐을 수 있습니다 |
| 펫이 화면 밖으로 나감 | `%USERPROFILE%\.poketokenpet\prefs.json` 에서 `petX`/`petY`를 `null`로 |

### 아직 실기 확인이 안 된 부분

코드에 Windows 분기는 다 넣었지만 **개발자가 mac에서만 돌려봤습니다.**
특히 이 세 가지는 실제로 확인이 필요합니다:

- **투명 창** — 펫 뒤에 검은 사각형이 보이면 알려주세요
- **펫 창 크기** — Electron은 Windows에서 크기 조절 불가 창의 `setBounds`를
  무시하는 걸로 알려져 있습니다. 그래서 창을 **처음부터 크게 만들고 줄이는**
  방식으로 짰습니다. 줄이기가 무시돼도 스프라이트는 잘리지 않고, 주변에
  보이지 않는 여백만 남습니다 (그 여백은 클릭이 통과합니다)
- **고DPI** — 배율 125%/150%에서 스프라이트가 뭉개져 보이는지

이상하면 스크린샷과 함께 알려주면 고칠 수 있습니다.
